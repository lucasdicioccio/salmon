# About

Salmon is written by Lucas DiCioccio, who also writes about it, and about the other tools it grows alongside, on his blog at [dicioccio.fr](https://dicioccio.fr/ ). The source is on [GitHub](https://github.com/lucasdicioccio/salmon ).

This site is itself generated by a salmon binary, `salmon-docs-sync`, which rebuilds the pages with Kitchen Sink from the repository's `resources/` and `specs/` directories.

## Sibling sites

- [Kitchen Sink](https://kitchensink-tech.github.io/ ) — the static-site generator this site is made with, and whose `documentation` layout the guides and specs use.

- [tramaj](https://lucasdicioccio.github.io/tramaj/ ) — the templating language of Kitchen Sink's sections.

- [agents-exe](https://lucasdicioccio.github.io/agents-exe/ ) — a runner for LLM agents.

- [acme-not-a-joke](https://lucasdicioccio.github.io/acme-not-a-joke/ ) — the ACME client behind salmon's certificate-signing recipes (`salmon-ops-recipes-experimental`).
